**Port Meridian** — an original open-world crime game built for make.fun's "Make GTA 6" bounty, $1,666 in USDC. You are Rico Vega, a driver fresh out of the docks, pulled into the Meridian Crew's war with the Harbor Kings. Explore a sun-soaked coastal city on foot and by car: steal cars, outrun the police, run 6 story missions with dialogue, fight with fists and a pistol, and take back Port Meridian. Everything is original — city, characters, story, art and synth sounds — with no Rockstar content. It plays offline in desktop Chrome from static files, keyboard + mouse, no network requests and no libraries.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Controls: WASD move/drive, E enter or steal a car, mouse aim, click shoot, F punch, Shift sprint, P pause, M mute. Progress saves automatically to localStorage.
